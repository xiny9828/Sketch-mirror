### ✨ 功能特性

- 📱 **安卓实时预览**｜告别传图发文件，Sketch 稿手机上即时看效果
- 🌐 **浏览器实时同步**｜电脑浏览器直接预览，修改自动刷新，流畅不卡顿
- 🖼️ **灵活倍率导出**｜PNG/JPG 任选，1/2/3 倍图按需切换，适配不同查看场景
- ⚡ **高效稳定不翻车**｜智能加载队列、缓存复用，设备连接、预览导出更靠谱
- 🎯 **画板自动跟随**｜选中 Sketch 画板自动同步预览，新手也能快速上手
- 🔒 **隐私安全**｜仅本地 WiFi 局域网传输，设计稿不上云，设备连接需要授权

### 🚀 使用方法

1. **打开电脑任何来源**：打开终端，输入 `sudo spctl --master-disable`，输入管理员开机密码（屏幕不显示字符），再按回车；打开 `系统设置”>“隐私与安全性`，向下滚动就能看到 `任何来源` 并勾选。【方法二：不开启任何来源，打开插件若报错，再在这里点击 `仍要打开` 也可以正常使用】

   <img width="735" height="342" alt="image" src="https://github.com/user-attachments/assets/ff1cb6a0-f006-4886-8e90-272a173008b0" />

2. **下载并安装插件**：下载 `SketchMirror.sketchplugin.zip`，解压后双击安装（Sketch ≥ 100）
   
   <img width="211" height="294" alt="image" src="https://github.com/user-attachments/assets/63bfd1e4-8ea8-45af-b5d8-9c7a4e01926b" />

3. **下载并安装 Android 客户端**：下载 `sketchmirror.apk` 并安装到 Android 设备
   
   <img width="270" height="587" alt="Screenshot_2026-10-28-11-30-32-184_com xiny9828 SketchMirror" src="https://github.com/user-attachments/assets/40d9ed37-e1b6-4bf2-ab0f-23d80a523511" />
   
4. **开启预览**：在 Sketch 中打开插件菜单「开启手机预览」或「开启浏览器预览」
   
   <img width="398" height="192" alt="image" src="https://github.com/user-attachments/assets/8424a01f-5c93-4e05-b3da-ff44f998b5dc" />

5. **连接设备**：确保手机与电脑在同一局域网，App 会自动发现电脑并连接
